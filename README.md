# 25 November 2026 — The World in One Image

![Competition badge](https://make.fun/badge/news-image-20261125.svg)
![Rank badge](https://make.fun/badge/news-image-20261125/Joppy26/news-image-20261125/rank.svg)

A one-page newspaper front page summing up Wednesday 25 November 2026:
Australia formally apologises to its LGBTQ veterans; Asian chip stocks
crash (Taiwan −7.2%, Korea −5.4%, Japan −3.3%); the International Day for
the Elimination of Violence against Women; Bitcoin slips below $60,000;
and inflation jumps (Australia CPI 4.9%, Japan services prices +4.2%).

Every story was checked against the day's reporting before it was drawn,
and the image itself was drawn from scratch with a Python program
(`draw.py`) using only simple shapes and DejaVu fonts — no photographs,
no copied artwork.

Entry for the [news-image-20261125 competition](https://make.fun/bounty/news-image-20261125)
on make.fun. `main.ts` copies `entry.png` to the output directory.
